# 折线声程几何核算服务

钢板对接焊缝超声斜射探伤专用的常驻几何核算服务。只做一件事：把斜射声束在板材上下表面之间来回反射的折线路径算清楚——一个来回（skip）多长、地面投影多远、回波声程对应的缺陷埋多深、经过了几次反射。

- 仅 HTTP/JSON 对外，无网页，不涉及探伤委托单与质检流程
- 运行时 Node.js 20 + Express
- 核心三角几何与 HTTP 层严格分离，可单测

## 几何模型

板厚 `T`、折射角 `β`（相对板面法线）、材料声速 `v`：

| 量 | 公式 |
|---|---|
| 半跨水平投影 | `T · tan(β)` |
| 半跨斜边声程 L | `T / cos(β)` |
| 一个 skip（完整来回，2 个半跨）声程 | `2T / cos(β)` |
| 一个 skip 地面距离 | `2T · tan(β)` |
| 一个半来回（1.5 skip，3 个半跨）声程 | `3T / cos(β)` |
| 回波埋深（相似三角形折叠反推） | `等效第一跨声程 · cos(β)` |

反射次数按折回规则计入：声束每走过一个完整半跨（触碰一次表面）计一次反射。
回波声程在半个 skip 到一个 skip 之间（首次返跨）时，埋深 = `(2L − S)·cos(β)`。
读数超过两个 skip 时先按跨折回再反推，**绝不把总声程直接当垂直埋深读**。

正入射极限 β → 0 时 skip 声程 → `2T`（声程严格大于 `2T`，单调收敛）。

**单位约定**：长度（板厚、声程、地面距离、埋深）必须使用同一长度单位；声速使用与该长度单位配套的单位。例如长度用 mm，则声速用 mm/s（钢中纵波约 5 900 000 mm/s、横波约 3 200 000 mm/s）。飞行时间 = 声程 / 声速。

## 接口

### `POST /geometry/skip`
返回半跨 / 一个 skip / 一个半来回的声程、地面距离、反射次数与飞行时间。

```json
{ "thickness": 20, "angleDeg": 45, "velocity": 5900000 }
```

基准算例（T=20, β=45°）：一个 skip 声程 = 40√2 ≈ **56.5685**，地面距离 = **40**。

### `POST /geometry/echo`
由回波声程反推缺陷位置（埋深、地面投影、所在半跨、反射次数、完成 skip 数）。

```json
{ "thickness": 20, "angleDeg": 45, "velocity": 5900000, "soundPath": 127.2792206 }
```

### 探伤配置（进程内，重启清空）
- `PUT /configs/:name` — 保存 `{thickness, angleDeg, velocity}`
- `GET /configs/:name`、`GET /configs`、`DELETE /configs/:name`
- 核算时传 `{"configName": "..."}` 即可复用；行内显式参数覆盖配置中的同名项，且只对本次调用生效
- 两套配置各自独立，板厚角度互不串扰

### 错误
非法输入返回 `400`，`error.details` 逐字段给出原因；配置不存在返回 `404`。
拦截规则：板厚必须为正；折射角必须在 (0, 90) 开区间（90° 声束贴板、走不出折线，在进入三角函数前打回）；声速必须为正；回波声程不得为负。

## 模块划分

```
src/
  geometry/leg.js      半跨 / skip 斜边声程几何
  geometry/ground.js   地面距离、反射次数、折回定位
  geometry/depth.js    相似三角形反推埋深
  configStore.js       探伤配置存取（仅运行期）
  validation.js        非法参数拦截
  service.js           用例编排（HTTP 层只调这里）
  app.js / server.js   HTTP 收发
test/                  几何关系 / 校验 / 配置 / 编排 / HTTP 端到端
```

回归测试钉住的几何关系：
1. 板厚翻倍 → 一个 skip 的声程与地面距离都翻倍
2. 板厚不变、折射角增大 → 地面距离变大、skip 斜边声程变长
3. 折射角趋零 → skip 声程收敛到 2T（正入射极限）
4. 斜射回波反算埋深与相似三角形几何自洽，不得读成总声程垂直深度
5. 45° 基准算例与手算值 `2T/cos45` 一致
